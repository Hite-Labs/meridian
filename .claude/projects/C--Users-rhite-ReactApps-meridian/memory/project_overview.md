Meridian is a web app for wellness/coaching practitioners to track client progress via standardized questionnaires, automated scoring, clinical flag detection, and trend dashboards.

**Why:** Core value prop is data-driven proof of results practitioners can show prospective clients.

**How to apply:** Demo scope — one seeded practitioner (Dr. Maya Chen), one seeded client (Sarah K.) with 8-session journey. No auth. Stack: Next.js App Router, Supabase, Tailwind CSS, Vercel deployment.
